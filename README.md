# Website RT 005 RW 05 Cilodong

Website statis HTML/CSS/JavaScript yang siap di-host di GitHub Pages.

## File
- `index.html` — halaman utama
- `style.css` — tampilan responsif
- `script.js` — menu mobile, notifikasi, dan tahun otomatis

## Upload ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `rt005-cilodong`.
2. Upload ketiga file tersebut ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan dan tunggu proses deployment.
7. Website akan tersedia pada alamat GitHub Pages repository.

## Logo resmi
Logo resmi RT 005 RW 05 Kelurahan Cilodong sudah disertakan sebagai `logo-rt005-rw05.jpg` dan otomatis digunakan pada header website.

## Integrasi aplikasi RT
Tombol dan kartu layanan sengaja dibuat mudah dihubungkan ke aplikasi/API RT pada tahap berikutnya.
